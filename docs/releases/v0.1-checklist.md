## Tag and release (after the merge and the validations above)

Not done yet. When every section is ticked:

```bash
git checkout main
git pull origin main

git tag -a v0.1.0 -m "Coffee Ready Indicator v0.1.0"
git push origin v0.1.0
```

Then move the `Unreleased` entries of `CHANGELOG.md` under `## [0.1.0] - <date>`,
set `COFFEE_SENTINEL_VERSION` in `platformio.ini` if it changed, and create
the GitHub Release from the tag with `firmware.bin` from the CI artifact.
